# UEA Speech Recognition Project

## Overview
A speech recognition system that recognises 20 spoken names using MFCC features and a CNN.

## Methods
- Python
- MFCC feature extraction (13 coefficients)
- CNN for speech classification
- 400 development recordings and 100 test recordings

## Results
- Linear: 62.50%
- Mel: 61.25%
- MFCC: 81.25% (validation)
- Independent test accuracy: 33%

## Project Files
- `feature_extraction.py` — Feature extraction
- `feature_comparison.py` — Feature comparison
- `train_model.py` — Model training
- `train_final_model.py` — Final model training
- `evaluate_test.py` — Testing
- `live_demo.py` — Live demonstration
